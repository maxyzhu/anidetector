Getting started

{% if not deployment %}

A deployment is one camera, at one place, over one stretch of time. Nothing infers it — camera id, location and country are human knowledge — so create it first.

uv run python manage.py shell -c "
from django.utils import timezone
from core.models import Deployment
print(Deployment.objects.create(
    camera_id='cam1', location='backyard', country='USA',
    start_ts=timezone.now(),
).id)"
{% endif %}

Everything in one command — creates a deployment if you omit --deployment, then registers, processes and identifies:

uv run python manage.py quickstart <folder>{% if deployment %} --deployment {{ deployment_id }}{% endif %}

Or step by step, which is what to use when something goes wrong:

uv run python manage.py register_video <folder> --deployment {{ deployment_id }}   # catalogue the files
uv run python manage.py process_video                          # decode -> tracks + motion
uv run python manage.py classify_species                       # SpeciesNet on each animal box
uv run python manage.py activity_report --sensitivity          # bouts across a threshold sweep

A GPU is picked up on its own — cuda, then mps, then cpu. Pin it with TORCH_DEVICE in .env, or per run with --device. Add --contiguous to register_video only when the files are one recording the camera split up, in filename order.
